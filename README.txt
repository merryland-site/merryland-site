Merry land — односторінковий сайт

1. Відкрийте index.html у браузері для попереднього перегляду.
2. Натисніть «Редагувати сайт» для зміни напрямків, фотографій і розкладу.
3. ВАЖЛИВО: редактор демонстраційний. Він зберігає дані лише у браузері, а не на сервері. Інші відвідувачі цих змін не побачать.
4. Для публікації змін усім відвідувачам натисніть «Експорт JSON», збережіть файл під назвою content.json поруч з index.html на хостингу. Видаліть локальні зміни або відкрийте в новому браузері для перевірки. Фото в JSON як data URL збільшують розмір файлу.
5. Для повноцінної безпечної онлайн-адмінпанелі потрібна серверна CMS з авторизацією і сховищем фотографій (наприклад, Supabase або Sanity). Поточна кнопка редагування не захищена паролем і НЕ є адмінпанеллю для продакшену.
6. Розмістіть папку на Vercel (через GitHub або інший спосіб завантаження статичного проєкту). Логотипи в assets/ оригінальні.
7. Уточніть остаточні HEX-коди кольорів: #8ad4f і #ffbd5 у ТЗ неповні. Наразі застосовано наближені #9cddff і #ffbd59.
